# Security policy

This plugin is an official Uzume plugin and follows the [Uzume security policy](https://github.com/phabioo/uzume/blob/main/SECURITY.md): supported versions, response times and scope are described there.

Report vulnerabilities privately through [Report a vulnerability](https://github.com/phabioo/uzume/security/advisories/new) in the Uzume repository, never in a public issue of this repository. Name this plugin, its id and version in the report.
